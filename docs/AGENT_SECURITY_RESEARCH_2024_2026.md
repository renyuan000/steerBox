# 2024-2026 Agent 安全研究与开发机制清单

## 文档定位与证据分级

本文整理与 `steerBox` 相关的近两年 Agent 安全研究、供应商数据行为争议和 AI 增强型攻击报道，目的是提炼开发时必须具备的安全机制。

证据标签：

- **官方资料**：供应商、标准组织或项目官方发布；
- **研究/复现**：论文、基准、研究者或社区可复现实验；
- **媒体/社区报道**：事件线索，不能单独当作事实闭环；
- **推断**：根据多个来源得到的工程判断；
- **待复核**：需要在当前版本、当前环境或授权目标上重新验证。

本文没有读取或处理任何 API key、token、credential 或供应商秘密配置。事件事实的当前版本状态仍需在进入产品决策前重新核验。

## 必要开发安全机制清单

### 1. Provider 与数据出口治理

- Provider、Endpoint、Model、Prompt 和 Agent Role 分层；
- 默认把第三方 Provider 视为不可信可见性边界；
- 发送前做数据分类、最小化、脱敏、可逆/不可逆伪名化和用户确认；
- 统一 egress gateway 记录目标、数据等级、摘要、策略结果、版本和拒绝原因；
- 支持本地模型、私有部署、零数据留存或合同约束作为策略输入；
- registry、prompt、trace、event 和 checkpoint 只保存 `auth_ref`，不保存密钥。

### 2. 控制流、数据流与 Prompt Injection

- 外部网页、邮件、Issue、日志、工具输出和情报都标记为不可信数据；
- 不允许工具输出直接改写系统目标、权限或批准状态；
- 工具调用前后分别执行 schema、目标、权限和副作用校验；
- 使用可信控制流与不可信数据流分离、数据流标签和 capability policy；
- 对高风险动作采用人工审批或人工接管，不能只由模型判断安全。

### 3. 记忆、RAG 与跨 Agent 信任

- 记忆记录来源、时间、作用域、置信度、版本和可撤销引用；
- 新内容先进入候选/隔离区，经过验证或人工确认再进入长期记忆；
- 检测冲突、重复、异常来源和低比例投毒；
- 跨项目、跨租户和跨 Agent 读取必须有 scope 和 capability；
- 记忆删除、降级、回滚和重新索引均可审计。

### 4. Tool、MCP 与插件供应链

- 工具 manifest 包含输入输出、权限、网络范围、side effect、版本和维护来源；
- 新工具默认禁用，安装、升级和提权需要审批；
- MCP/插件服务器不视为天然可信；
- 工具执行在沙盒、最小权限和资源预算内进行；
- 工具结果可验证、可超时、可取消、可重放或明确不可重放。

### 5. 运行时、任务和副作用安全

- `GoalContract` 明确目标、禁止项、停止条件、预算、授权和验证；
- `PolicyGate` 在计划、工具调用、外发、写入和处置前拦截；
- `SideEffectLedger` 记录可恢复、不可恢复、补偿和回退边界；
- `EventLog` 是事实源，Trace/Board/Memory 是可审查的派生或辅助记录；
- 长期任务支持暂停、取消、租约过期、紧急停止和人工接管；
- 跨模型 fallback 不能静默降低能力、权限或验证标准。

### 6. 可观测、审计与验证

- 记录模型、prompt、工具、策略、数据出口、人工决策和版本；
- 保留原始证据引用、摘要、哈希、时间和访问审计；
- 对模型输出做事实、权限、schema、代码和安全规则验证；
- 建立 Prompt Injection、记忆投毒、工具污染、供应商外传和越权处置回归集；
- 对长期运行按事件抽样评估，不把一次成功当成持续安全证明。

### 7. 供应商政策与法律暴露应对

Agent 侧无法单独解决供应商的留存政策、执法请求或跨境管辖权问题。可执行的工程应对是：数据分级、禁止敏感数据外发、Provider allowlist、合同和留存策略校验、出口审计、私有/本地模型和可切换路由。供应商法律政策必须由组织法务、采购和安全责任人共同评估，不能伪装成单一 Agent 开关已经解决。

## 开发前置门禁

在进入安全评估或安全运营代码实现前，至少应完成：

1. Shared Harness threat model 和 trust boundary；
2. `AuthorizationContract`、`ResponseAction`、`Evidence` 和数据分级 schema；
3. Provider egress、secret 引用和日志脱敏策略；
4. Prompt/tool injection、记忆投毒和插件供应链测试集；
5. 高风险动作审批、紧急停止和可恢复/不可恢复副作用验证。
