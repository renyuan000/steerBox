# steerBox 智能体研发路线图

## 文档定位

本文把 `steerBox` 的长期研发方向收敛为四个专业方向，并说明它们与共享 Harness、Phase 1 和后续验证阶段的关系。

本文是研发规划，不是已实现能力清单。除非另有真实代码、运行日志或测试证据，文中“应支持”“计划实现”均属于规划状态。

## 总体结构

```text
Shared Agent Harness
  ├── 软件开发智能体
  ├── 持续运维智能体
  ├── 安全评估与漏洞研究智能体
  └── 安全运营智能体
```

产品展示可以将四个方向投影为两个产品族：

- 工程智能体：软件开发 + 持续运维；
- 安全智能体：安全评估与漏洞研究 + 安全运营。

研发和权限边界仍以四个专业方向为准。安全评估可以被安全运营编排调用，但不能隐藏为安全运营内部一个不受独立授权的工具。

## 共享底座优先级

四个方向共用以下底座能力：

1. `GoalContract`、`LoopController`、`Task / TaskRun / Attempt`；
2. `ToolRegistry`、能力授权、`PolicyGate` 和人工介入模式；
3. `EventLog`、`StateStore`、`TraceStore`、`Evidence` 和 `SideEffectLedger`；
4. `RecoveryCheckpoint`、心跳、租约、超时、取消、暂停、恢复和幂等；
5. 多模型 `ProviderProfile / ModelProfile / PromptProfile / RouteDecision`；
6. 任务看板投影、查询控制面和可审计命令；
7. 记忆、知识、规则和系统演进的证据与审批边界。

长期运行目标是 7x24 常驻和多年可恢复生命周期。长期运行不等于无限权限：授权、预算、数据访问和高风险动作都必须有期限和策略边界。

## 分阶段路线

### Phase 1：Harness + 软件开发垂直切片

目标：用一个真实软件开发任务验证共享 Harness 的目标、工具、验证、事件、检查点、人工介入和看板投影闭环。

范围：单 Portfolio、单 Project、本地顺序执行、至少一个真实模型适配器、静态多模型 fixture、事件重建的只读 BoardProjection。

不在范围：分布式调度、完整安全运营、自动渗透执行、自动安全处置、完整 TUI/Web、自动全局进化。

验收重点：任务状态合法迁移、证据可追溯、失败可复盘、检查点可恢复、重复变更不重复产生副作用。

### Phase 2：长期运行与持续运维切片

目标：在 Phase 1 Harness 上增加周期任务、事件触发任务、心跳/租约、后台运行、服务健康和受控恢复。

持续运维首批场景：健康巡检、变更观察、故障分析、容量/性能分析、成本和混合云资源只读治理。

验收重点：服务重启后任务状态连续；巡检结果有证据；恢复动作有审批、回退或不可恢复标记；后台任务可被聊天查询、暂停和接管。

### Phase 3：安全评估与漏洞研究切片

目标：建立授权、隔离、验证和报告闭环，支持代码/依赖/配置/暴露面分析，以及隔离环境中的 PoC 模拟验证。

验收重点：没有有效 `AuthorizationContract` 时不能创建主动验证任务；范围、时间窗口、允许工具、停止条件和副作用可审计；验证结果可回传开发和安全运营任务；修复后能够复测。

### Phase 4：安全运营常驻切片

目标：建立持续接入、检测关联、调查、受控处置和效果验证闭环。

首批场景：日志和告警关联、资产暴露变化、漏洞情报匹配、后门/恶意样本摘要分析、事件调查和低风险遏制。

验收重点：后台任务可长期运行；用户可以随时进入上下文；高风险动作必须审批或人工接管；处置后有独立效果验证；规则和知识更新有来源、版本、回滚和回归结果。

### Phase 5：跨项目编排与受治理进化

目标：在已有单项目契约稳定后，增加 Portfolio 级调度、跨项目依赖、并行 worker、资源租约和受治理的策略/工具/记忆演进。

验收重点：跨项目变更有 ownership、冲突和 join 策略；进化对象有证据、负面证据、兼容性约束、审批、回滚和回归验证。

## 依赖与禁止的捷径

- 领域智能体不能绕过共享 `PolicyGate`、`EventLog`、`Evidence` 和 `SideEffectLedger`；
- 安全评估不能因为被安全运营调用而继承无限权限；
- 安全运营不能把模型输出直接当成情报事实或处置命令；
- 多模型切换不能静默丢失 prompt、版本、路由和验证上下文；
- 常驻任务不能只依赖进程内存或模型上下文；
- 看板是事件和状态的投影，不是事实源，也不能绕过控制面直接写事实。
